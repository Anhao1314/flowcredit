## 1. 五条传导链

```
物理链    电力 → 数据中心 → 芯片/加速器 → 加速器库存 → 算力云(Neocloud) → token
商业链    token → 收入 → 经营现金流
金融链    加速器库存 → GPU抵押贷款 → 算力承购 → 可转债 → 偿债义务
信用链    终端用户 → 应用 → 模型 → 算力承购 → 算力经营者 → 经营现金流 → 偿债义务
主张链    算力云 → token → TAI → CCI   （我们的主链：token 是计量原子）
```

**物理链**回答"算力从哪来"（后面）；**信用链**回答"算力往哪去"（前面，钱从终端价值一级级传到偿债）；**主张链**是我们把两者接起来的方式——token 是前后的交点。
