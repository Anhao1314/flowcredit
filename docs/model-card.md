# FlowCredit 评估模型卡（Model Card）

**模型**：FlowCredit 风险引擎 `flowcredit.risk_result/v0.2.1` + 资本结构叠加 `flowcredit.capital_structure/v0.2.0`（含 distress 闸门）
**版本日期**：2026-11-20
**维护方**：FlowCredit

## 1. 用途

**设计用途（intended use）**：AI 算力经营者（推理/GPU 云/矿业转型）的 VC 级尽职调查与交易对手风险筛查。输出为**评估参考**：经营真实性、单位经济、增长质量、证据缺口与偿债画面。

**明确不用于（out of scope）**：
- 授信批准、拒贷或额度设定
- 违约概率（PD）、预期损失（EL）或定价
- 任何自动执行/交易决策
- 对上市公司股价或市值的预测

## 2. 输入与证据分级

- **19 字段经营输入**（token 活动、GPU 小时、回款、客户结构、资本结构等）
- **公开数据**：SEC XBRL 财务事实（documented 级）；10-K/10-Q/S-1/424B4 申报全文抽取（documented 级，**弱于 XBRL**，模式冻结、逐项带原文片段）
- **证据包**：用户上传（documented，sha256 摘要，不一致字段 fail-closed）
- **显式信用事件库**：每条事件必须带申报出处（如 8-K accession）；无出处不入库

## 3. 输出

- TAI（token 活动指数）、CCI（五维可信度指数）、风险等级（A≥800 / A-≥750 / B≥650 / C≥500）、decisionStatus
- 资本结构叠加：solvency 分数、CCI 上限（`600 + 4×solvency`）、distress 闸门（EBIT 覆盖<1 / 经营利润率<−50% / 现金跑道<6 月 / 负权益，只压不抬）
- 指纹：inputFingerprint / assessmentFingerprint / evaluationFingerprint，可反查审计

## 4. 验证状态（截至 2026-11-20）

| 验证项 | 结果 | 含义 |
|---|---|---|
| CORZ 案例回放 | 2022-09-30 申报 → distress 闸门 cap 600（Grade C）；首次预警 2022-03-31（破产申请前约 7 个月） | **个案通过**，不构成统计有效性 |
| 深度回放（24 季度，12 家**幸存者**宇宙） | 代理标签：119 标注，recall 0.88，FPR 0.798；事件标签：130 标注，3 正例，recall 1.0（单事件） | 闸门召回高但区分度低；事件标签样本为零统计意义 |
| 校准表（事件标签） | 基准事件率 2.3%；3 个正例全部落在 551–650 桶（3.4%）；≤550 桶 19 例 0 事件；单调性**不成立**；Brier 0.022 vs 基准 0.023 | **评分的历史含义尚未建立**——诚实结论 |
| 因子研究 | grossMargin/interestCoverage 的 |t|>2（探索性）；DD 为结构基准；评分模型草案样本外跑输 DD，未采纳 | 仅供研究，不接入引擎 |

**对外口径**：只可说"**可审计的评估**"，**不可说"已验证的预测"**。

## 5. 已知限制

1. **幸存者偏差**：研究宇宙为 12 家现存公司。完全退市公司（如 STHD）价格源与 SEC 注册表双缺失；外国发行人（如 ARBK，20-F）无 XBRL 事实——死公司暂时进不了样本
2. **标签稀疏**：已核实的信用事件仅 1 个（CORZ 破产）；市场代理标签会漏掉"股权变彩票"案例
3. **文本抽取**：申报全文抽取为 documented 级，弱于 XBRL；模式覆盖有限（承诺/流动性/股本）
4. **无 PD/EL**：引擎红线，任何数字都不是违约概率
5. **单一市场/行业**：美股 AI 算力运营商；跨行业泛化未验证
6. **中期数据未经审计**：10-Q/S-1 中期报表为 unaudited

## 6. 治理

- **权威边界**：LLM 永不写入 TAI/CCI/等级/decision；数字只来自确定性引擎
- **门禁**：规则/权重/标签模式变更 = 版本升级 + golden 重算 + 人工评审
- **可审计**：全链路指纹；审计日志仅存哈希（不存正文）
- **诚实披露优先**：不可验证 ≠ 通过；FAIL 永久记录；空桶显示"样本不足"而非 0%
