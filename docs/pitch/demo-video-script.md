# FlowCredit 演示视频剧本

**版本**：v1 · 2026-11-26
**主片长**：约 90 秒（可剪 60 秒 / 30 秒）
**形式**：屏幕录制 + 旁白 + 少量字幕卡；真实交互，不预录结果
**一句话**：一次可审计的算力信用评估——从 Anthropic 的 9009 亿承诺，到一家运营商的裁决卡，再到 NVIDIA 的公开数据与治理事件。

---

## 0. 叙事结构

```
前面（需求） Anthropic 424B4：9009 亿承诺 / 707 亿 12 个月内到期
中间（被评） 示例运营商 Acme Inference：一句话 → 裁决卡 → what-if
后面（供给） NVIDIA：公开财务 → 公开数据出不了 TAI/CCI
旁证（治理） NVIDIA 8-K Item 5.02：辞任 / 复任，独立 overlay
收束        Agent 做完评估，引擎决定数字，人负责批
```

**核心记忆点**：
1. 钱已经到了算力这边，信用还没到。
2. 高分不等于可授信：CCI 929 / A，但证据 41/100、decision 证据不足。
3. 它不会假装知道：公开数据出不了 TAI/CCI；治理事件也不做股价预测。

## 2. 旁白全文（可直接照读）

**[0:03]**

## 4. 剪辑说明

- **Anthropic**：预热后约 3 秒；冷启动可能 17 秒，建议预热或 2–3x 加速，保留“424B4 · documented 级”标注。
- **Acme**：实时约 4–6 秒；保留实时执行轨迹的 1–2 秒，再切裁决卡。
- **What-if**：实时约 5 秒；保留 929→914 的数字变化，不要剪掉。
- **NVIDIA**：预热后约 5 秒；冷启动约 7 秒。
- **治理事件**：约 4–5 秒；保留“非信用事件标签 / 非股价预测”一行。
- 关键数字加字幕，停留 2–3 秒；CCI/证据质量那一帧可放大 105%。
- 背景音乐：低频、无歌词、音量 −24 dB 左右；旁白优先。

## 6. 口径红线

- 不说“已验证的预测”“模型准确率”；只说“可审计的评估”。
- 不说“3 个信用事件”；准确口径是 **1 个破产（CORZ）+ 2 个交易所合规通知（CIFR/MARA）**。
- 不说 PD、违约概率、额度、授信结论；引擎不产出。
- 治理事件明确标注：**不是信用事件标签，不做股价预测**。
- 不把 NVIDIA 的公开财务当成 TAI/CCI；公开数据只能做资本结构/偿付印象。
- 所有画面均为真实交互；不预录、不伪造结果。
