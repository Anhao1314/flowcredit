## 公开边界

本仓库是公开仓库。以上材料**不含**融资额、客户数据、密钥或非公开信息；请勿向其中添加这些内容。

演示与演讲里涉及的产品能力，以当前仓库代码与 `docs/model-card.md` 为准；不要把演讲中的简化说法当成模型口径（例如：不说“已验证的预测”，不把公开数据当成 TAI/CCI）。
