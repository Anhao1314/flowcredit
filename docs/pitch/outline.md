## 0. 演讲目标

**听众**：投资人 / 大赛评委 / 潜在设计伙伴
**听完必须记住三件事**：
1. 算力正在金融化，这是必然趋势，不是概念。
2. 算力金融化缺一层信用设施——这是结构性机会。
3. FlowCredit 是这层设施：agent 形式，确定性灵魂，可审计、可复现、人负责。

**行动号召**：成为前三个设计伙伴；或进入融资/合作下一步。

**叙事公式**：时代必然 → 结构性缺口 → 我们的答案 → 可验证的凭据 → 商业路径 → 终局。

## 2. 逐页大纲

### 第 1 页 · 我们为什么要做这个产品（90s）

**目的**：先讲动机——时代给了什么条件、我们看到了什么缺口、为什么必须由我们做。
**要点**：
- AI 竞争从模型转向算力；算力从技术成本变成生产要素。
- 产业链：后面是电力/数据中心/芯片/加速器/算力云；前面是应用/模型/算力承购；中间是 token。
- 金融化已经开始：GPU 抵押贷款（两百亿美元级）、算力承购、可转债。
- 历史规律：铁路→铁路债；房地产→按揭与评级；电力→项目融资。基础设施金融化，必然长出信用设施。
- 算力的信用层，还是空的。
- 我们做这个产品，不是因为 AI 热：我们一边做确定性量化研究，一边评估 AI 算力经营，每天看到两套语言对不上。
- 缺口不会因为多一个大模型消失，它需要一层新基础设施——这就是 FlowCredit 的起点。

**关键句**：「这就是我们做 FlowCredit 的原因。」
**视觉**：算力产业链图（前/后/中间 token），或"基础设施金融化"时间轴。
**过渡**：「为什么是现在？先看钱走到了哪一步。」

---

### 第 2 页 · 算力已经是钱（50s）

**目的**：把宏观趋势拉到眼前，用具体数字制造紧迫。
**要点**：
- Anthropic 上市：市值约 1.8 万亿美元（2026-11-19）。
- 招股书：未来算力与相关承诺 9009 亿美元；其中 707 亿 12 个月内到期。
- 算力已是资产负债表最大一行、金融合约、信用。
- 放钱的人（银行/基金/租赁）没有看得懂算力经营的报表。

**关键句**：「给算力经济，装上信用仪表盘。」
**视觉**：三个大字数字 `1.8T / 900.9B / 70.7B`，配一句"钱已经到了"。
**过渡**：「为什么看不懂？因为两套语言。」

---

### 第 3 页 · 两套语言，没有翻译（65s）

**目的**：把问题定义成结构性的，而不是"缺一个工具"。
**要点**：
- 算力语言：token、GPU 小时、回款率、客户集中度。
- 金融语言：现金流、偿债能力、押品价值。
- 传统评级看不懂 token 收入；VC 尽调靠人肉、不可复现；LLM 会编数字。
- 后果不是理论：CORZ 2022 破产——前缝需求断裂 + 后缝资本到期墙；我们的回放提前约七个月亮红灯。

**关键句**：「两套语言之间，没有翻译。」
**视觉**：左右两栏语言对照；下方 CORZ 时间线（2022-03-31 预警 → 2022-12-21 破产）。
**过渡**：「我们的翻译方式，不是造一个更大的模型。」

---

### 第 4 页 · 算力是因子，信用是结果（55s）

**目的**：给出思想内核，建立智力差异化。
**要点**：
- 算力是因子 X，信用是结果 Y；不是预测算力，而是用算力经营痕迹预测信用。
- token 是同时连接需求端与供给端的计量原子。
- 五条链：物理链、商业链、金融链、信用链、主张链。
- 风险不在链上，在接缝：需求断裂、客户集中、芯片贬值、资本到期墙、押品坍塌、假流量。
- 知识图谱是所有评估的底图。

**关键句**：「风险不在链上，在接缝上。」
**视觉**：五链图 + 六个接缝风险标注。
**过渡**：「所以产品长什么样？」

---

### 第 5 页 · 引擎给出什么（85s）

**目的**：让听众清楚输出，不陷入技术细节。
**要点**：
- 输入 19 个经营字段。
- 输出：TAI（token 活动真实性，0–100）、CCI（五维可信度，0–1000）、等级 A/A-/B/C、缺口清单。
- 资本结构叠加：solvency、CCI 上限；四道 distress 闸门（EBIT 覆盖<1、经营利润率<−50%、现金跑道<6 月、负权益），只压不抬。
- agent 形式，确定性灵魂：模型只收集/编排/解释，不写权威字段。
- 全链路指纹、证据分级、fail-closed；人说 yes 才生效。

**关键句**：「agent 形式，确定性灵魂。」
**视觉**：一张评估结果卡片（TAI / CCI / Grade / Decision / 指纹），旁边四道闸门图标。
**过渡**：「但引擎只是心脏。真正把评估做完的，是 agent。」

---

### 第 6 页 · agent 到底有什么用（80s）

**目的**：回答"为什么是 agent，而不是表单/计算器"；把产品从分数变成工作流。
**要点**：
- 先破误解：agent 不是用来算分的，算分是引擎的事。
- 四个用处：
  1. 一句话开始：自然语言/BP/JSON/CSV → 抽取、对齐、追问。
  2. 缺什么补什么：缺口清单 + 可照抄示例 + 补一条重评一次。
  3. 敏感性分析：回款率 96%→90%，CCI 929→914，等级与驱动因子。
  4. 自己取数：SEC 10-K/10-Q/XBRL/算力承诺、港交所公告；MiniMax 案例。
- 对分析师=几小时初筛；对资金方=第二意见+压力测试；对投资机构=可比较、可复现。

**关键句**：「别人卖你一个分数，我们交给你一条可审计的评估流水线。」
**视觉**：四格工作流（开始→补证→敏感性→取数），或真实对话截图 + 卡片。
**过渡**：「凭什么信？」

---

### 第 7 页 · 我们敢说"不知道"（80s）

**目的**：建立信任；这是全场的情绪高点，也是品牌。
**要点**：
- 所有人都在卖"AI 很准"，我们卖"可信"。
- 历史回放：12 家上市公司、24 季度 PIT；CORZ 提前约七个月（个案，不宣称统计有效）。
- 因子研究：13 个因子，多重检验校正后 2 个存活；不拿"AI 选出十个信号"讲故事。
- 校准与模型卡：Brier 0.022 vs 基准 0.023；公开写"评分的历史含义尚未建立"；不编 PD。
- 工程底座：22 个工具、460 个自动化测试、SEC/港交所自主采集、Finch 上架。

**关键句**：「我们宁可说不知道，也不编一个违约概率。」
**视觉**：回放时间线 + 校准分桶图 + "诚实边界"清单。
**过渡**：「这样的东西，谁付钱？」

---

### 第 8 页 · 从"第二意见"切进去（50s）

**目的**：说清客户、切口、收费与现状。
**要点**：
- 三类客户：放款机构（GPU 抵押/租赁/私人信贷）、算力基金（PE/VC/对冲）、算力市场与承购方。
- 切口：投前尽调的第二意见——不替代流程、几天交付、按评估收费。
- 路径：第二意见 → 贷后监控 → API。
- 现状诚实：无收入、external alpha、找前三个设计伙伴。

**关键句**：「第二意见卖的不是报告，是可审计的信任。」
**视觉**：三类客户 + 三步路径（第二意见→贷后→API）。
**过渡**：「往远看，这件事的终局是什么？」

---

### 第 9 页 · 算力经济的信用层（35s）

**目的**：收束到基础设施叙事，留下记忆点。
**要点**：
- 算力会像电、像带宽一样成为基础设施；合约金融化，token 票据化。
- 每一笔算力合同、每一笔 GPU 融资，都应有可审计的信用档案。
- 不预测股价，不替人决策。
- 收尾四句：AI 负责想，机器负责算，人负责批，全程录像。

**关键句**：「AI 负责想，机器负责算，人负责批，全程录像。」
**视觉**：一句话 + Logo；或"算力—信用层"示意图。
**收尾**：谢谢；可选加融资/合作一句话。

## 5. 叙事纪律（不讲什么）

- 不讲"AI 很火，所以我们做 AI 风控"——me-too。
- 不讲"模型准确率"——不可验证，且与品牌相反。
- 不讲"什么都能评"——只做算力经营者。
- 不讲"预测算力"——算力是因子，信用是结果。
- 不承诺 PD、违约概率、额度、授信结论。

## 6. 答辩锚点

| 问题 | 一句话答案 |
|---|---|
| 和穆迪/标普的区别 | 他们评全行业，我们评算力经营者的经营真实性；输出评估参考，不输出评级/PD |
| 数据从哪来 | 公开数据（SEC/港交所）+ 客户字段 + 证据包；给不出证据就是"证据不足" |
| 为什么是 agent | 输入脏、流程多步、输出要解释；agent 做流水线，引擎做权威；有界、可降级 |
| 会不会编数字 | 数字不经过模型；模型无写权限；指纹可复算 |
| 为什么是你们 | 带出处的标签库 + 校准纪律，两样都需要时间；外加算力链接缝理解 |
| 市场多大 | GPU 抵押贷款两百亿美元级，且增长；每个放款/承购决策都是评估需求 |
| 可复制吗 | 单点可复制，标签库+证据链+校准记录不可复制 |
| 监管合规 | 不做授信决策，不输出 PD；全链路审计；定位评估参考 |
| 下一步 | 3 个设计伙伴、10 次合格评估、1 个复购、1 个补证重评 |
